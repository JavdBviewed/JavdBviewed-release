1.0.0

- 桌面客户端首次公开发布（Windows x64 安装包）
- 本地目录扫描：添加或重扫目录，自动识别视频文件并解析番号，每个文件成功/失败分别标记
- 引擎刮削：按番号走已配置引擎搜索，取回标题、封面等元数据
- 确认入库：扫描结果经用户确认后写入番号库（云同步），同一番号自动去重
- 已看状态：本地播放进度云同步，看完自动标记为真实已看
- 检查更新：内置更新检查（默认关闭，环境变量开启），下载走国内镜像加速候选链，sha256 校验
- 媒体源播放：支持 Emby 等源直连播放

Desktop release gate passed for 1.0.0; NSIS installer, blockmap, and latest.yml are ready.
