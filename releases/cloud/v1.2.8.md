# Cloud 1.2.8 正式发布

Cloud 1.2.8 现已作为正式稳定版本发布。本版本聚焦云侧新作品扫描的韧性与可观测性：探活失败分型到人话文案、同因连败抑制（后台任务列表不再每分钟刷行）、云扫描跟随拓展同步的 JavDB 线路自动换线，以及暂停态的前端警示。

## 主要变化

### 新作品扫描（探活失败分型）

- 探活失败由单一「probe failed」细分为三类并逐字透传到「后台任务」列表备注列：
  - transport 层失败（超时 / 连接拒绝 / DNS / 代理拨号失败）；
  - 目标站返回 403（疑代理出口 IP 被限频）；
  - 其他 HTTP 错误码（429 / 5xx / 404 等，带具体码）。

### 新作品扫描（同因连败抑制与退避）

- 同因连续失败时不再每分钟落新行：首败落行，同因续败就地更新既有行为「（已连续失败 N 轮）」，同因 10 分钟退避窗内静默（不探活、不落行）。
- 覆盖第四类原因：会话解密失败（degraded / session-decryption）——管理台改密或容器重建后未重新登录期间，同样不再刷行。
- 换因（如 403 恢复后变为 transport）重置计数并落新行；成功轮清零全部连败字段。

### 新作品扫描（线路跟随）

- 云扫描基址跟随拓展端同步过来的 JavDB 线路配置（settings 实体 routes.javdb）：候选=首选线路→主线路→启用的备用线路，仅 https、限 4 个白名单镜像域（含子域）、上限 5 条候选，非法条目静默过滤。
- 每轮从上次可用线路起环选探活，首个可达线路即本轮基址（轮内不换线）；全败按最后被探候选的原因落行。
- 无线路配置 / 配置全非法时回退环境变量默认基址，行为与旧版一致。

### 界面

- 扫描状态 tab 顶部新增暂停警示横幅（扫描暂不可用 + 最近原因 + 已自动退避重试提示），与进行中横幅互斥不闪烁。
- 后台任务进度行（存量再过滤任务）：进度 10 分钟无变化时追加「进度已停滞」提示，有进展即消失。

## 数据兼容

- 无 DB schema 变更、无新表、无新增 settings 键。
- 扫描状态 JSON 新增 5 个内部字段（旧数据零值兼容，回退旧版自动忽略）；scan_runs 表结构不变。
- `GET /v1/admin/scan/status` 新增 1 键 `scanLine`（当前扫描线路，空=默认基址），既有 26 键契约不变。
- 旧版拓展/客户端零感知；会话推送、同步、管理台契约均不变。

manifest 与镜像 OCI labels 的 commit/buildNumber/obfuscated 状态一致（commit=db28c47fc0eba6065b8990342418325af756aa10，buildNumber=git-db28c47fc0eb，obfuscated=true）。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.8
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.8@sha256:3b34515ccf2944bcb121dbe32504c8aeae789be2050480646b717a9f7b81d7c4
```

部署后请访问 `/version`，确认 `version` 为 `1.2.8`、`buildNumber` 为 `git-db28c47fc0eb`。

## 启动后检查

- 访问 `/health`，确认服务返回正常状态。
- 管理台可登录；「新作品扫描」页三个 tab 正常；若扫描处于暂停态，状态 tab 顶部出现暂停警示横幅。
- 若此前「后台任务」列表每分钟刷「probe failed」行：升级后同因失败将就地更新为「（已连续失败 N 轮）」且 10 分钟退避窗内静默，列表不再增长。
- 若 JavDB 会话处于「会话解密失败」降级态：登录一次管理台即自愈（自愈后最多 10 分钟退避窗内静默，随后自动恢复探活）。
- 若拓展端已配置多条 JavDB 线路：升级后云扫描自动跟随，`/version` 无需任何操作；单线路 / 未配置线路用户行为不变。
- 任一客户端执行一次同步，确认正常无报错。
- 其余业务数据保持不变。
