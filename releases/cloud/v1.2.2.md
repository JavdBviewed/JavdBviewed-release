# Cloud 1.2.2 正式发布

Cloud 1.2.2 现已作为正式稳定版本发布。本版本优化大批量同步的传输效率与可恢复性，并收紧改密后的会话安全边界。

## 主要变化

- 大型同步请求优先使用 gzip 压缩传输，并把待同步队列分批发送，减少单次请求压力。
- 相同内容的网络重试会被识别为确认，不会重复生成 Cloud 增量记录。
- 改密后会立即撤销所有设备会话；扩展和其他客户端需要使用新密码重新登录。
- 运行日志和磁力推送日志不再作为用户资产同步；升级后的首次同步会清理当前账号 Cloud 中这两类历史数据。
- 同步窗口支持取消请求，并区分显示实际传输大小与压缩前 JSON 大小。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.2
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.2@sha256:0942e9e1cc86792096db98dd963929b217b3c225e704ff527b57fd4227b99c47
```

部署后请访问 `/version`，确认 `version` 为 `1.2.2`、`buildNumber` 为 `git-1486ce040f42`。

## 启动后检查

- 访问 `/health`，确认服务返回正常状态。
- 如近期修改过 Cloud 管理员密码，请在扩展或其他客户端中使用新密码重新登录。
- 安装新版扩展后执行一次 Cloud 同步，确认历史 `log` 和 `magnet_push_log` 已清理，其余业务数据保持不变。
