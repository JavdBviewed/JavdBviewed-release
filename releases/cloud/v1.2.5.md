# Cloud 1.2.5 正式发布

Cloud 1.2.5 现已作为正式稳定版本发布。本版本强化云侧新作品扫描：管理台可接管扫描参数、扫描与版本更新通道支持出站代理与探活、扫描任务记录可清空。

## 主要变化

### 新作品扫描（增强）

- 管理台接管扫描参数：设置页新增「扫描」块，可配置总开关、扫描间隔（分钟）与批量（条/轮）；生效优先级为管理台 > 拓展端 > 内置默认，扫描状态页显示配置来源（管理台/拓展/默认）与当前生效值。
- 拓展端新增配置回读端点 GET /v1/scan/config：拓展按凭据读取云端生效配置，旧版本拓展不受影响（端点不存在或失败时静默回退本地配置）。

### 出站代理（新增）

- 设置页新增「出站代理」块：配置 HTTP/SOCKS5 代理，保存即热生效，无需重启；作用面覆盖新作品扫描与版本更新检测，可设「仅扫描使用」。
- 支持环境变量兜底：`CLOUD_OUTBOUND_PROXY` 与 `CLOUD_OUTBOUND_PROXY_FOR_SCAN_ONLY=1`；管理台配置优先于环境变量，两者皆空为直连。
- 「测试连通」探活：对已保存的通道发一次真实请求，结果分型（超时/端口未开放/认证失败/服务错误/其他），保存前即可确认代理可用。
- 代理地址在 API 响应、审计日志与运行日志中一律脱敏（密码位 `****`）；凭据以明文存于数据目录 cloud.db 设置表，整库快照与数据库备份同样包含凭据，备份信任面与整库一致。

### 其他

- 后台任务页（新作品扫描任务记录）新增「清空」按钮：二次确认后清空记录并回显清空条数，不影响扫描本身。
- 部署文档新增「出站代理」节：两环境变量、优先级、热生效、凭据边界与探活分型说明。

## 数据兼容

- 无 DB schema 变更。
- settings 新增 `scanConfig`（扫描参数接管）与 `outbound`（出站代理）两个键，均为普通 KV 合并，多设备同步兼容；旧客户端/旧拓展不识别新键，不受影响。

## 校验和

发布门禁产物见 CI 工件 `cloud-release-1.2.5`（`release/` 目录）：

```text
release/release-manifest.json  79cee232f0d1026aec6352980c17d3ade3599e639c417b29f46c02fbb8cb004a
```

manifest 与镜像 OCI labels 的 commit/buildNumber/obfuscated 状态一致（commit=42736021602e6d1015514a0e3984f94ed5ad1bd4，buildNumber=git-42736021602e，obfuscated=true）。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.5
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.5@sha256:3d5aab94114f07c4f7abd36ed22bb4df384526809e3e5b326fc93fd779bb7ce7
```

部署后请访问 `/version`，确认 `version` 为 `1.2.5`、`buildNumber` 为 `git-42736021602e`。

## 启动后检查

- 访问 `/health`，确认服务返回正常状态。
- 管理台可登录，设置页「扫描」与「出站代理」块正常打开，扫描状态页显示配置来源。
- 任一客户端执行一次同步，确认正常无报错。
- （可选）配置出站代理后点「测试连通」确认代理可用；在「新作品扫描」页点「立即跑一轮」，确认后台任务记录正常写入。
- 其余业务数据保持不变。
