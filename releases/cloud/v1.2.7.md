# Cloud 1.2.7 正式发布

Cloud 1.2.7 现已作为正式稳定版本发布。本版本让云侧新作品扫描应用内容过滤设置（分类白名单 / 分类黑名单 / 状态与日期过滤），并为已扫出的存量提供「批量再过滤」；扫描会话解密密钥改为管理台登录/改密时自愈，扫描页界面重构为三个 tab。

## 主要变化

### 新作品扫描（内容过滤）

- 云扫描入库前应用拓展侧同步过来的过滤设置：
  - 分类白名单：命中时自动拼入列表请求的 `?t=` 参数；
  - 分类黑名单：对候选作品抓取详情页解析分类标签，命中即跳过；解析失败保守保留，不误删；
  - 状态过滤：日期范围、排除已收录、排除已看过、排除已浏览、排除想要。
- 分类字典内置（一次性从拓展端内置列表嵌入），无运行时依赖；拓展端后续新增分类时字典存在漂移窗口，以拓展端为准的核对逻辑已内置。
- 去重双修：修正 video tag 口径的历史特例（G1）与跨 ID 空间重复入库（G2），同一作品不再重复产生记录。

### 新作品扫描（存量再过滤）

- 管理台「新作品扫描 → 扫描设置」新增「存量清理」卡：先预览（命中数、原因分布、样本列表），再输入 `REFILTER` 确认执行。
- 范围仅限云扫描自身写入的行（sourceType=cloud-scan）；命中行落墓碑并同步到各端；可重复执行，幂等。
- 预览/执行支持同步与异步任务两种形态，异步任务进度显示在「后台任务」页；扫描轮进行中触发时返回 409（job-running / scan-running），不产生重复抓取。

### 新作品扫描（会话密钥自愈）

- 管理台登录或修改密码成功时运行时注入会话解密密钥：改密后无需重建容器、无需改 .env，重新登录一次即恢复。
- 「立即跑一轮」触发前增加会话预检：无会话 / 会话解密失败 / 密钥未就绪时直接返回 409 明确码（session-missing / session-decryption / session-key-missing），管理台给出人话提示，不再空跑一轮。
- 扫描状态页会话态四分支大白话展示；出站探活不可用时标注「本轮未探活」。

### 界面

- 「新作品扫描」页重构为三个 tab：扫描状态 / 后台任务 / 扫描设置。
- 出站代理行增加「去设置」深链直达设置页对应区块。
- 后台任务支持 10 秒轮询，扫描进行中显示进度横幅。

## 数据兼容

- 无 DB schema 变更、无新表、无新增 settings 键。
- 既有 new_work / video 数据不变；「存量清理」只在你手动执行后对 sourceType=cloud-scan 的命中行落墓碑。
- 旧版拓展/客户端：GET /v1/scan/config 契约不变，回读兼容；扫描设置卡为管理台新增区块，旧端不感知。

## 校验和

发布门禁产物见 CI 工件 `cloud-release-1.2.7`（`release/` 目录）：

```text
release/release-manifest.json  251f5b91f8f2cb7ede468e821fd796f35709cfbf9f4b75336e2f1524b2df262d
```

manifest 与镜像 OCI labels 的 commit/buildNumber/obfuscated 状态一致（commit=9cc119ba5f0a3eab7ff1823e38b658b942245b67，buildNumber=git-9cc119ba5f0a，obfuscated=true）。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.7
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.7@sha256:b302c237468afc8037538561d9133064d2e1c8503324b6c9ac24dee1454c47a9
```

部署后请访问 `/version`，确认 `version` 为 `1.2.7`、`buildNumber` 为 `git-9cc119ba5f0a`。

## 启动后检查

- 访问 `/health`，确认服务返回正常状态。
- 管理台可登录；「新作品扫描」页为三个 tab（扫描状态 / 后台任务 / 扫描设置）；「扫描设置」tab 可见「存量清理」卡。
- 若此前扫描处于「会话解密失败」降级态：登录一次管理台即自愈；若 JavDB 会话已过期，从拓展端重推会话后再登录。
- （可选）确认 NWC 过滤设置已同步到云后，在「扫描状态」页点「立即跑一轮」，确认按过滤设置抓取。
- （可选）对升级前已扫出的存量，在「扫描设置 → 存量清理」卡执行一次预览与批量再过滤。
- 任一客户端执行一次同步，确认正常无报错。
- 其余业务数据保持不变。
