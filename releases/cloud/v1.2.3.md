# Cloud 1.2.3 正式发布

Cloud 1.2.3 现已作为正式稳定版本发布。本版本让媒体源删除在所有客户端之间真正一致，并修复历史脏游标可能导致的同步报错。

## 主要变化

- Emby/Jellyfin 媒体源删除现在会记录为永久墓碑：在任一客户端删除媒体源后，该删除会同步到 Cloud 并传播到其他设备，旧源不会被后续同步重新带回。
- 服务端对历史会话游标做宽松归一化，不再因脏游标数据触发同步接口报错。

## 已部署用户升级

Cloud 不会自动替换或重启你的容器。升级前请先在管理台的数据页面创建快照，并备份宿主机的 `data/` 目录。

如果你使用 Compose：

```bash
docker compose -f compose.yaml pull
docker compose -f compose.yaml up -d
```

需要固定在本版本或回滚时，将 `.env` 中的 `CLOUD_IMAGE_NAME` 改为：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.3
```

本版本镜像 digest：

```text
ghcr.io/javdbviewed/javdbviewed-cloud:1.2.3@sha256:c4ecaeb22f87b5c2e88f6220851fc53b5d0a97c0f6003df96abcc999df424d7f
```

部署后请访问 `/version`，确认 `version` 为 `1.2.3`、`buildNumber` 为 `git-ecd1cb2b07dd`。

## 启动后检查

- 访问 `/health`，确认服务返回正常状态。
- 在任一客户端删除一个 Emby/Jellyfin 媒体源，再让另一台设备执行同步，确认该源不会出现。
- 其余业务数据保持不变。
